**Exact irreducible components of intersections of two Hassett divisors, with an interactive explorer and a complete finite catalogue through discriminant 500.**

This MIT-licensed Python implementation follows **Yang–Yu, Algorithm 7.6**, including all admissible integral overlattices and isometry deduplication preserving the square of the hyperplane class. The engine uses only the Python standard library. The explorer includes a standalone offline catalogue and loads the larger dataset on demand when hosted over HTTPS.

**Version 1.1.0** contains every unordered pair of distinct valid labels with **6 < d ≤ 500**: **165 labels, 13,530 intersections, and 1,636,925 component records**. This adds **13,464 pairs** to the original 66-pair catalogue. These are totals counted separately for each label pair; the same geometric locus can occur in several intersections. The complete finite range does not exhaust the infinitely many valid labels. See [the expanded catalogue guide](docs/expanded-catalogue.md) for results, verification scope, and reproduction commands.

## Interactive website

Open the [Hassett Lattice Explorer](https://hassett-lattice-explorer.causetpatrick.chatgpt.site) in a browser. Choose a preset such as **C₈ ∩ C₁₄** or **C₈ ∩ C₂₆**, or enter another pair through 500, then select a component to inspect its lattice.

The hosted explorer reads the catalogue index and fetches the selected pair's compressed certificate, checking its hash and size. Its **66 embedded pairs through discriminant 42** remain available as an offline fallback. The downloadable `web/explorer.html` opens without a server or internet connection and accepts additional plain JSON results generated by the Python engine. The browser displays exact computed results; the general classification runs in Python. A document preview may suppress JavaScript, so open the HTML in a browser or use the hosted website.

## Quick start

Requires Python 3.10 or later. From this directory:

```bash
python -m hassett_lattices intersect 8 14
python -m hassett_lattices intersect 8 26 --output c8-c26.json
python -m unittest discover -s tests -v
```

The first two commands compute **five** and **eight** components, respectively. Open `web/explorer.html` in a modern browser to inspect the bundled catalogue, or load an exported JSON file in that explorer.

Optional installation:

```bash
python -m pip install .
hassett-lattices intersect 20 12 --json
```

There is no need to install SageMath, Magma, NumPy, or SymPy. The optional PDF and browser-development workflows require additional tools; the algorithm and tests do not.

## Python API

```python
from hassett_lattices import intersection_components, Limits

answer = intersection_components(8, 14)
assert answer['complete']
assert answer['component_count'] == 5

for component in answer['components']:
    print(component['determinant'], component['gram'])
    print(component['k3_association'])

# Explicitly adjust resource limits for a larger calculation.
answer = intersection_components(
    98, 206,
    limits=Limits(max_work=20_000_000, timeout_seconds=120),
)
```

Inputs must be distinct integers greater than six and congruent to zero or two modulo six. Their order is normalized according to the cases of Yang–Yu's algorithm; it need not be ascending. The original pair remains in `input_pair`. A self-intersection is deliberately rejected: as a set it is the divisor itself, not the rank-three problem treated here.

## What is computed

The output classifies the **reduced irreducible components** of the intersection in the moduli space of smooth complex cubic fourfolds. Each component has generic algebraic lattice of rank three and codimension two in moduli.

Each JSON result contains:

- A complete list of component Gram matrices and determinants.
- The distinguished class `h = [1, 0, 0]`, meaning the cohomology class usually written `h²`.
- Every retained origin: normalized pairing `tau`, saturation index, residues, and inclusion matrices.
- Explicit norm-two witnesses for rejected base matrices.
- Exact whole-lattice K3 admissibility, including the split-lattice congruence condition.
- Diagnostics for the finite search and a `complete: true` flag only on successful completion.

The default budget is 5,000,000 work units and 60 seconds. `ResourceLimitError` aborts a calculation that exceeds either bound. The CLI exits with status 2 and does not write a partial result. Use `--max-work`, `--timeout`, or the explicit `--no-limits` option as needed. This is an exhaustive algorithm with configurable computational limits, not a bounded heuristic reported as a proof.

No multiplicities, explicit equations, or birational maps are produced. An affirmative K3 flag is a Hodge-theoretic result, not an automatic rationality verdict. A negative flag refers to the generic rank-three lattice; more special higher-rank points can acquire an associated K3 surface.

## Interactive catalogue

The explorer displays the incidence network, component matrices, candidate pairing scan, saturation origins, label arithmetic, and whole-lattice K3 status. Its two data tiers are:

| Mode | Labels | Pairs | Component records | Data access |
|---|---:|---:|---:|---|
| Embedded offline fallback, d ≤ 42 | 12 | 66 | 628 | Included in the standalone HTML |
| Expanded catalogue, d ≤ 500 | 165 | 13,530 | 1,636,925 | Index plus one compressed pair file at a time over HTTPS |

The graph is schematic. Its positions and crossings are not geometric coordinates in moduli. A pair outside the loaded catalogue is not an empty intersection. Use the Python CLI and JSON import for additional pairs.

Rebuild the bundled catalogue from the engine:

```bash
python scripts/build_catalogue.py
```

This build checks the five published fixtures and injects the 66-pair dataset into `web/explorer.html`. Nondeterministic timings are omitted from mathematical result files. Use the sharded runner for a larger finite range:

```bash
python scripts/expand_catalogue.py --max-discriminant 500 --gzip \
  --output ../hassett-expanded-500 --seed-catalogue web/catalogue.json
python scripts/verify_catalogue.py ../hassett-expanded-500/catalogue-index.json \
  --no-limits --report docs/catalogue-verification-500.json
```

Repeating the runner command resumes the calculation: completed files are checked before reuse, and failed or pending pairs are retried. An incomplete batch remains explicitly incomplete. For a fresh independent rebuild, use a new empty output directory and omit `--seed-catalogue`. Packaging and static website build commands are in [docs/expanded-catalogue.md](docs/expanded-catalogue.md).

Among the expanded component records, **1,371,455** have an admissible rank-two K3 label in the displayed lattice and **265,470** do not. The latter statement concerns the generic rank-three lattice; more special points can acquire extra algebraic classes. The largest retained saturation index is **68**. None of these statistics is a rationality decision.

## Mathematical design

The computation has five stages:

1. Write normalized rank-three Gram matrices with one unknown integer pairing.
2. Use a strict determinant inequality to enumerate exactly the positive definite cases.
3. Reject matrices containing a square-two vector, using proved finite coordinate bounds.
4. Enumerate every integral overlattice in which both original labels remain primitive; preserve distinguishedness and reject square-two vectors again.
5. Identify the survivors by an exact integral isometry preserving `h²`.

Primitivity of the first label forces an index-n overlattice to have basis `(h², u, (a h² + b u + v)/n)`, and primitivity of the second is precisely `gcd(b,n)=1`. Together with `n² | det(G)`, this yields a finite and complete saturation search. The detailed proof, implementation formulas, and interpretation of primitive embeddings appear in `docs/mathematics.md` and `docs/implementation.md`.
