Component inspector

From two labels to all components.

The implementation follows Yang–Yu, Algorithm 7.6. Positive definiteness only begins the calculation: compatible overlattices and isometries are essential to a complete answer.

01 / ENUMERATE

A finite family of Gram matrices

Choose the normalized rank-two bases with h² · μ = ε₁ and h² · ν = ε₂, where each εᵢ ∈ {0, 1}. Only the mixed product τ = μ · ν remains.

(3τ − ε₁ε₂)² < d₁d₂

This exact inequality makes the search finite.

02 / EXCLUDE

Remove forbidden roots

Reject a candidate containing an integral vector of square two. The calculation uses an exhaustive, positive-definite bound, with an explicit vector as a rejection witness.

vᵀGv = 2

A root in the base remains a root in every overlattice.

03 / SATURATE

Include compatible overlattices

Search finite-index extensions in which the distinguished class has even orthogonal complement and both original rank-two markings stay primitive. Recheck the root condition.

disc(M′) = disc(M) / n²

Skipping this step can miss entire components.

04 / IDENTIFY

Quotient by marked isometry

Compare lattices by integral isometries fixing h². A shared determinant is not a sufficient test. The resulting admissible rank-three classes determine the irreducible loci.

UᵀG′U = G,   U(h²) = h²

Different parameter and saturation routes can meet the same class.

What this says about rationality.

An associated K3 surface is a Hodge-theoretic statement. For a rank-two marking of discriminant d, Hassett’s arithmetic condition excludes factors 4, 9, and odd primes congruent to 2 modulo 3.

The conjectural link to rationality goes beyond this arithmetic. This explorer identifies lattice components and K3 admissibility; it does not infer a rational parametrization from a successful K3 test. Rationality of particular families requires separate geometric theorems.

Even when a very general member has exactly the displayed rank-three lattice, special points can acquire additional algebraic classes and lie on further Hassett divisors. The graph records only the selected incidences.
